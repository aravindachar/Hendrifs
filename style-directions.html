Core Tab: three style directions

Each option below is the same app, with the same controls, dressed in a different style. Each draws on design patterns common in today's amp and modelling apps, not on any single app's screens. The knobs work: drag them up or down. Pick one, or mix parts.

A · Faceplate closest to Architect

The real amp panel on screen: round knobs, LEDs and MOD / DLY / REV buttons that behave like the hardware (off → red → green focus). A patch list sits on the left, and the deeper Architect-only controls are in cards below. Desktop editors and remotes for amps tend to look like this.

B · Signal chain modern modeller style

Your sound as a row of blocks: input → gate → amp → mod → delay → reverb → cab → out. Tap a block to edit it in a big panel below, and tap its dot to switch it on or off. Most current modelling and smart-amp apps use this layout because it scales well from phone to tablet.

C · Stage play live, edit later

Huge patch pads, big effect switches, one fat gain slider and an always-on tuner readout. It's designed to be hit with a thumb while holding the guitar, like the live or performance modes many amp apps offer. Pair it with A or B for deep editing.

Building blocks

Whichever you pick, the app shares these: one knob component (drag up or down, the arc shows the value), LEDs that copy the amp's meaning (red = on, green = focused, amber = tempo), and a dark stage-friendly palette.
